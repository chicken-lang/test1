## 0. 技术栈选型

### 0.1 选型原则
- 与需求文档推荐保持一致（NFR-MAINT-06、第 9.1 节、第 5.2 节）
- 全栈 TypeScript，降低上下文切换成本
- 优先成熟、社区活跃、等保三级友好方案
- 移动端流量占比 ≥ 70%（NFR-COMPAT-06），需独立移动端适配

### 0.2 前端技术栈（用户端 + CMS 后台）

| 类别 | 选型 | 理由 |
|---|---|---|
| 框架 | Vue 3（`<script setup>` + Composition API） | 需求文档明确推荐；生态成熟 |
| 语言 | TypeScript 5 | NFR-MAINT-01 代码规范 |
| 构建 | Vite 5 | 用户熟悉；HMR 快 |
| 用户端组件库 | Element Plus（PC）+ Vant 4（移动端 H5） | NFR-MAINT-06 推荐组合 |
| CMS 组件库 | Element Plus | 第 9.1 节推荐 |
| 状态管理 | Pinia | 第 9.1 节推荐 |
| 路由 | Vue Router 4 | 标准 |
| HTTP | Axios + 拦截器 | 标准 |
| 富文本 | WangEditor 5（主）+ TinyMCE 6（备） | 国产、中文友好；FR-99.05 |
| 图表 | ECharts 5 | 看板（FR-99.17） |
| 图标 | Iconify（@iconify/vue） | 按需加载 |
| SSR/SSG | Nuxt 3（用户端，SEO 友好）；CMS 用 SPA | NFR-SEO 系列要求 |
| 国际化 | vue-i18n（预留，本期简体） | NFR-I18N-02/03 预留 |
| 表单校验 | Element Plus Form + Zod | 类型安全 |
| 测试 | Vitest + Vue Test Utils + Playwright | NFR-MAINT-02/04 |

### 0.3 后端技术栈

| 类别 | 选型 | 理由 |
|---|---|---|
| 语言/框架 | NestJS 10（TypeScript） | 与前端同语言；模块化；企业级 |
| ORM | Prisma 5 | 类型安全；迁移管理 |
| 数据库 | PostgreSQL 16 | 主库；全文检索 `tsvector` 兜底 |
| 缓存 | Redis 7 | NFR-PERF-11 缓存命中率 ≥ 80% |
| 搜索引擎 | Elasticsearch 8 | NFR-PERF-04 搜索 ≤ 500ms（10 万级） |
| 消息队列 | RabbitMQ | 异步：邮件、短信、索引重建、病毒扫描 |
| 对象存储 | MinIO（自建）/ 阿里云 OSS | 附件存储 + CDN（第 6.3 节） |
| 认证 | JWT（Access ≤ 2h + Refresh）+ SSO | 第 8.2 节 |
| SSO 协议 | OAuth 2.0 / OIDC（主）+ CAS（兼容） | 第 8.2 节 |
| 限流 | @nestjs/throttler + Redis 令牌桶 | NFR-SEC-13 登录限流 |
| API 文档 | OpenAPI 3.0 + Swagger UI | NFR-MAINT-05 |
| 验证 | class-validator + class-transformer | DTO 校验 |
| 日志 | Pino（结构化） | 高性能 |
| 测试 | Jest | NFR-MAINT-02 |

## 1. 实施总览

### 1.1 阶段与里程碑

| 阶段 | 名称 | 关键里程碑 | 依赖 |
|---|---|---|---|

## 12. 子任务 Check List 模板说明

为保证每个子任务独立可执行、可验证，统一模板如下：

```
### T{阶段}.{序号} {任务名}

**任务目标**：一句话说明产出。

**所需资源**：人力 / 账号 / 环境 / 第三方。

**关键里程碑**：可演示的中间产物。

**验收标准**：可客观判定的通过条件（对应 DoD 条目）。

**Check List**
- 执行前（准备 / 依赖确认 / 环境就绪）
  - [ ] ...
- 执行中（关键步骤 / 验证点）
  - [ ] ...
- 完成后（质量检查 / 联调验证 / 文档归档）
  - [ ] ...
```

### 12.1 约定
- 每个 T 任务可在 1-3 人日内完成（业务模块除外）
- 每个 T 任务对应一个 feature 分支 + PR
- PR 必须含：实现说明、自测截图、Check List 勾选
- 合并需 1+ 同事审查（NFR-MAINT-07）

### 12.2 依赖关系
- M0 → M1 / M3（并行）
- M1 → M2 / M6
- M2 + M3 → M4
- M4 → M5
- M4 + M5 + M6 → M7
- M7 → M8 → M9

### 12.3 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| SSO 协议未确认 | 阻塞 M6 | 早期与信息化办对齐，先做本地账号 |
| 原站抓取受限 | 阻塞 M8 | 提前申请授权 + 备份导出 |
| 等保测评周期长 | 阻塞上线 | 同步启动材料准备 |
| 富文本编辑器兼容性 | 影响 M2 | 早期技术预研（WangEditor/TinyMCE 对比） |
| ES 数据同步延迟 | 影响搜索时效 | 采用 CDC（Debezium）或 1 分钟定时 |
