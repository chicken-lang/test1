### 1.2 典型业务场景

#### S1：学生查询课表与成绩
1. 进入教务处首页
2. 右上"快速通道"点击"全校课表查询"或"成绩查询"
3. 跳转至数字管理系统（教务管理系统）
4. 用学号 + 密码 / 校园卡 / 微信扫码 登录（SSO）
5. 查询课表 / 成绩

#### S2：教师发布教学比赛通知
1. 教师（角色 R2）收到业务口（角色 R3）发布的"教学能力大赛"通知
2. 访问教务处首页 → "通知公告（教师）"栏目
3. 阅读通知
4. 下载中心下载参赛申报表
5. 项目评审系统提交材料
6. 教务处审核 → 公示 → 推荐

#### S3：学生办理休学
1. 学生（角色 R1）进入"办事指南" → "学籍事务" → "学籍异动"
2. 阅读"学生办理休学流程"
3. 线下填写休学申请表 → 因病者校医院签署 → 学院签署 → 民族学生学生部签署 → 教务部审批
4. 学生凭离校手续单办理离校手续

#### S4：二级学院参加专项工作会议
1. 二级学院教学秘书（角色 R4）访问教务处首页
2. 点击"通知公告"或"教务管理"栏目
3. 查找会议通知（如"学士学位授权审核专项工作协调会"）
4. 确认时间、地点、参会人员
5. 准时参会

#### S5：访客了解学校专业建设成果
1. 校外访客（角色 R5）通过搜索引擎或招生网站进入教务处首页
2. 点击"专业建设"或"教研教改"或"专业白皮书"（参考深大）
3. 查看高水平专业群验收公示、国家级 / 省级课程
4. 跳转学校主站了解专业详情

#### S6：教学反馈（师生意见）
1. 师生（角色 R1/R2/R6）进入"教学反馈"栏目
2. 填写反馈表（在线表单）
3. 教务处（角色 R3）受理、回复、归档

#### S7：投诉举报
1. 师生（角色 R1/R2）进入首页或页脚"联系我们"
2. 查看"投诉举报方式"（参考深大）
3. 通过电话 / 邮箱 / 现场方式反馈
4. 教务处登记、调查、反馈

#### S8：教师查看上课时间表
1. 教师（角色 R2）进入"办事指南" → "上课时间表"
2. 查看本学期上课时间
3. 与"校历"对照安排教学

### 4.3 面包屑规范

- **格式**：`首页 > 一级栏目 > 二级栏目 > 文章标题`
- **分隔符**：`>`（推荐）
- **链接**：除"文章标题"外，其余均可点击
- **位置**：页面顶部 H1 下方

### 4.4 URL 规范

- **一级栏目**：`/{pinyin}`，如 `/about`、`/rules`
- **二级栏目**：`/{pinyin}/{pinyin}`，如 `/rules/national`
- **列表页**：`/{pinyin}/{pinyin}?page=1`
- **详情页**：`/{pinyin}/{pinyin}/{id}.html`，如 `/manage/notice/2311.html`（参考深职大 `/info/1215/2311.htm` 体系）
- **附件下载**：`/attachment/{id}/{filename}`，避免泄漏真实路径
- **静态资源**：`/static/{type}/{filename-with-hash}`，启用 CDN + 永久缓存
- **API**：`/api/v1/{module}/{action}`，RESTful 风格
- **CMS 后台**：`/admin` 或 `/cms`，独立子域名 `cms.jwc.sziit.edu.cn`
- **URL 必须小写**、**避免特殊字符**、**不含中文**

### 4.5 站点地图

- **HTML sitemap**：`/sitemap`，列全站栏目与重要文章（≤ 1000 链接）
- **XML sitemap**：`/sitemap.xml`，自动生成，分片（≤ 5 万 URL / 文件）
- **分片 sitemap**：`/sitemap-{section}.xml`（栏目 / 文章 / 标签 / 学院）
- **sitemap 索引**：`/sitemap-index.xml`
- **robots.txt**：`/robots.txt`

## 6. 富文本 / 表单 / 附件支持

### 6.1 富文本支持

- **段落** `<p>`
- **标题** `<h1>` ~ `<h6>`
- **列表** `<ol>` / `<ul>` / 自定义序号
- **表格** `<table>`（含表头、合并单元格）
- **图片** `<img>` + `<figure>` + `<figcaption>`
- **链接** `<a>`（外链加 `rel="noopener noreferrer"` + `target="_blank"`）
- **加粗 / 斜体 / 下划线 / 删除线**
- **引用** `<blockquote>`
- **代码块** `<pre><code>`、行内 `<code>`
- **公式** MathJax / KaTeX
- **图表** 嵌入 ECharts
- **视频 / 音频** 嵌入 H5 播放器
- **附件** 列表 + 图标 + 文件大小 + 下载次数
- **流程图** 嵌入 Mermaid / 图片
- **不支持 / 慎用**：iframe（沙箱问题）、Flash（已淘汰）、ActiveX（已淘汰）

### 6.2 表单字段类型

- 单行文本、多行文本、富文本
- 数字、日期 / 时间 / 日期时间
- 单选 / 多选 / 下拉、级联选择
- 开关、滑块
- 文件上传、图片上传（含裁剪）
- 评分、地理位置
- 验证码（图形 / 短信 / 滑块）
- 签名（移动端）
- 手机号（校验）、邮箱（校验）、身份证号（校验 + 脱敏存储）、学号 / 工号（校验 + 关联用户）
- 自定义校验规则

### 6.3 附件支持

- **支持格式**：
  - 文档：`.doc` / `.docx` / `.pdf` / `.wps` / `.rtf` / `.txt` / `.md`
  - 表格：`.xls` / `.xlsx` / `.csv`
  - 演示：`.ppt` / `.pptx`
  - 图片：`.jpg` / `.jpeg` / `.png` / `.gif` / `.webp` / `.svg`
  - 压缩：`.zip` / `.rar` / `.7z`
  - 视频：`.mp4` / `.webm`（内嵌）
  - 音频：`.mp3` / `.wav`（内嵌）
- **大小限制**：
  - 单文件：≤ 100MB（可配置）
  - 单次上传：≤ 500MB
- **存储**：对象存储（OSS / COS / MinIO）+ CDN
- **病毒扫描**：对接云厂商扫描服务
- **版本管理**：同一附件支持多版本
- **下载统计**：按日 / 周 / 月统计
- **防盗链**：Referer 校验 + 临时 URL + Token

- **用户信息同步**：定时同步 + 实时事件（部门、姓名、邮箱、手机）
- **Token 管理**：JWT + Refresh Token；Token 过期时间 ≤ 2h
- **统一注销**：单点注销
- **权限映射**：教务处账号 → 自动获得"教务处用户"角色
- **审计日志**：所有 SSO 登录记录

### 8.3 API 设计规范

- **RESTful**：GET / POST / PUT / PATCH / DELETE
- **版本**：`/api/v1/` 前缀
- **状态码**：标准 HTTP 状态码
- **响应格式**：
```json
{
  "code": 0,
  "message": "success",
  "data": { ... },
  "trace_id": "abc123"
}
```
- **错误码**：业务错误码（如 `40001` 参数错误、`40101` 未登录、`40301` 无权限）
- **分页**：`page`、`size`、`total`、`items`
- **排序**：`sort` 参数（如 `-created_at`）
- **筛选**：`filter[key]=value` 或 `filter[key]=in:a,b,c`
- **搜索**：`q` 参数
- **字段选择**：`fields=id,name,email`
- **限流**：100 QPS / IP（可配置）
- **幂等性**：POST 接口支持 `Idempotency-Key`
- **安全**：HTTPS + Token + 签名（防重放）
- **文档**：OpenAPI 3.0 + Swagger UI + ReDoc
- **Mock**：Postman / Apifox
