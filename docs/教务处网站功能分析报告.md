## 1. 网站整体概述

### 1.1 站点定位 🟢 [实测]
面向全校师生、面向社会公众的**教学管理与服务门户**，承担以下职责：
- 教学通知、公告、公示的发布与归档；
- 教学管理制度的公开与查询；
- 与教务管理系统、教学项目平台、智慧教室、教材管理等业务系统的入口聚合；
- 教学资源（人才培养方案、表格、文件、课程）的下载与共享。

### 1.2 用户角色 🟢 [实测 + 🟡 推断]
| 角色 | 主要诉求 | 关键操作 |
|---|---|---|
| 在校学生 | 了解选课、成绩、考试、教材、重修等通知；查课表、查成绩、看校历、作息时间 | 查看通知公告、跳转教学平台、查看作息时间 |
| 任课教师 | 了解教学安排、教学比赛、教材征订、培训；使用智慧教室 | 查看规章制度、查看教研教改、跳转教学平台 |
| 教务处工作人员 | 发布通知、发布公示、维护栏目 | 后台 CMS 管理（不开放给前端） |
| 二级学院院长 / 教学秘书 | 报送材料、参加教学工作会议、查询制度、查阅高水平专业群验收 | 下载中心、规章制度、教学反馈、跳转项目评审系统 |
| 校外访客 / 家长 | 了解学校教学概况、专业建设、竞赛获奖 | 部门介绍、专业建设、技能竞赛、教学荣誉 |
| 督导员 / 教学信息员 | 反馈教学情况、查看听课安排 | 教学反馈、规章制度 |

### 1.3 站点技术形态 🟡 [推断]
- **结构**：典型旧式 CMS（静态 HTML 框架 + 动态列表）型站点；
- **URL 规范**：
  - 一级栏目：`/{拼音缩写}.htm`，如 `/bmjs.htm`、`/jwgl.htm`
  - 子栏目/文章：推测为 `/{栏目}/{子栏目}.htm` 与 `/{栏目}/{id}.htm`（待验证，多数当前 404）
  - 静态资源：`/images/{xxx}.gif`、`/images/arr01.gif`（装饰图、箭头、底图）
  - 框架结构：`<table>` 嵌套，年代久远（IE 时代风格）
- **页面技术**：`<table>` 表格布局 + `<img>` 切片图 + `<iframe>` / JS 加载列表；
- **图片存储**：装饰图、栏目图标位于 `/images/` 目录下；
- **附件下载**：暂未观察到统一附件下载模式（栏目主体多空，附件机制待验证）。
