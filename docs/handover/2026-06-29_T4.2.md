## 1. 本次完成内容

### T4.2 列表页通用模板 ✅
实现栏目列表页通用模板,支持筛选(年度/月份/标签)+ 分页 + 置顶加红 + 空状态 + 侧边栏,URL query 可分享。

**Mock 数据扩展**(`apps/web/mock/data.ts`):
- 类型:`ColumnCategory`(栏目)/ `ListItem`(列表项)/ `SideItem`(侧边栏项)
- 数据:`columns`(15 栏目,含父子关系 + listStyle 配置)
- 函数:`queryList`(分页+筛选查询)/ `getFilterOptions`(年度/标签选项)
- 数据:`hotArticles`(热门 8)/ `recommendArticles`(推荐 6)
- 每个栏目生成 28 条确定性数据(覆盖 2024-2026 三个年度,便于分页验证)

**列表组件**(三种样式,根据栏目 listStyle 自动切换):
- `components/list/ListCard.vue`:卡片样式(图文并排,适用于教务管理/实践教学/教研教改)
- `components/list/ListTable.vue`:表格样式(日期块+标题,适用于通知公告/规章制度/下载中心)
- `components/list/ListCompact.vue`:紧凑样式(纯标题列表,适用于智慧教室/项目指南/办事指南)

**通用组件**:
- `components/list/ListFilter.vue`:筛选区(年度/月份/标签,按钮组样式,支持重置)
- `components/common/AppPagination.vue`:分页(包装 el-pagination,layout=total/prev/pager/next/jumper)
- `components/common/Sidebar.vue`:侧边栏(栏目导航 + 热门排行 + 推荐文章)
- `components/common/Breadcrumb.vue`:面包屑(首页 > 栏目 > 子栏目)

**页面**:
- `pages/list/[slug].vue`:栏目列表页
  - URL:`/list/[slug]?page=1&year=2026&month=6&tag=通知`
  - 从 route.params.slug 获取栏目,从 route.query 读取筛选/分页(支持分享)
  - 根据 `currentColumn.listStyle` 自动选择列表组件
  - 筛选/分页变化时 `router.push` 更新 URL query(筛选变化自动重置页码)
  - 空状态:el-empty + 重置筛选按钮
  - SEO:useSeoMeta 设置标题与描述

**导航更新**(`components/layout/AppNav.vue`):
- 内容栏目 path 改为 `/list/[slug]`(规章制度→/list/regulations,通知公告→/list/notices 等)
- 首页/部门介绍/校历作息保持原路径

## 4. 设计要点

### 列表样式分配(栏目 listStyle 字段)
- `table`:规章制度、通知公告、下载中心(信息密集,标题+日期为主)
- `card`:教务管理、实践教学、专业建设、教研教改、技能竞赛、教学荣誉(需展示摘要)
- `compact`:智慧教室、项目指南、教学反馈、办事指南(纯标题列表)

### URL query 可分享
- 所有筛选/分页状态写入 URL query(page/year/month/tag)
- 筛选变化时自动重置 page=1
- 直接访问带 query 的链接可还原筛选状态

### 置顶与加红
- `isTop`:置顶排序在前,样式加左边框/背景
- `isImportant`:标题文字变红加粗
- 排序:置顶在前,其次按发布日期倒序

### 适老化
- 所有组件在 `[data-color-mode='elderly']` 下增大字号
- 分页按钮增大点击区域
