## 2. 当前项目状态

### 技术栈
- Monorepo:pnpm workspace(apps/web + apps/admin + apps/server + packages/shared)
- 前端:Nuxt 3 + Vue 3 + TypeScript + Element Plus + @iconify/vue + Pinia + SCSS
- 主题色:#005BAC(深信院蓝)
- 适老化:@nuxtjs/color-mode([data-color-mode='elderly'])
- 代码规范:ESLint 9 flat config + Prettier + Stylelint + Husky + commitlint

### 运行方式
```bash
# 启动前端开发服务器
pnpm dev:web
# 访问 http://localhost:3000
```

### 已知问题(已修复)
1. **ESLint `consistent-type-imports` 规则报错**:需要 typed linting,已改为 'off'
2. **Nuxt 自动导入函数被 ESLint 报 no-undef**:已在 globals 中添加 useSeoMeta/useHead/useRoute 等
3. **stylelint 无法解析 SCSS**:已更新 .lintstagedrc.json,SCSS 只走 prettier
4. **components 子目录组件命名前缀问题**:已通过 `pathPrefix: false` 解决
